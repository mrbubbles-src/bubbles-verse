# Supabase Access

`@bubbles/supabase-access` enthält kleine, app-neutrale Supabase-Helfer für
Bubblesverse-Apps.

Aktuell teilt das Paket nur Cookie-Optionen und den optimistischen
Supabase-Session-Cookie-Check für Next.js-Proxies. App-spezifische
Autorisierung, Allowlisten, Projektmitgliedschaften, Redirect-Regeln,
RLS-Policies und Queries bleiben bewusst in den Apps.
